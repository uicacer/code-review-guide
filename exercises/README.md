# Exercises

Hands-on practice for the [tutorial](../tutorial/). Each exercise lets you practice a level's skill on real material in this repository, so you do not need a project of your own. Every exercise has an answer key, but try it yourself first.

| Exercise | Practices | Tutorial level |
|---|---|---|
| [level-1-feedback/](level-1-feedback/) | Rewriting review comments in the Conventional Comments style, kindly and clearly | [Level 1](../tutorial/level-1-feedback.md) |
| [level-2-review/](level-2-review/) | A full priority-order review of a small project: run the automation, then find what the tests miss | [Level 2](../tutorial/level-2-systematic.md) |
| [level-3-ai-phi/](level-3-ai-phi/) | Reviewing an AI-generated pull request that touches patient data: find the bugs, run a STRIDE-lite adversary pass | [Level 3](../tutorial/level-3-expert-and-ai.md) |

> Level 0 (Git and pull-request mechanics) is best practiced with GitHub's own interactive courses, linked from [Level 0](../tutorial/level-0-mechanics.md). There is no exercise for it here.

## How to use an exercise
1. Open the exercise folder and read its `TASK.md`.
2. Do the task yourself. Write your answers down (comments, a list of issues, a fix).
3. Only then open `answer-key.md` and compare.

All sample data in these exercises is synthetic. None of it is real patient information, and none of it should ever be replaced with real patient information.
